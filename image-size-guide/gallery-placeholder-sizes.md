# Gallery Placeholder Crop & Export Guide

This guide explains how to prepare your images so they fit the **current gallery placeholder layout** more cleanly before upload.

> Note: The website is responsive, so placeholder display sizes change across devices. These are **not fixed exact pixel requirements**. Focus on **aspect ratio** first.

## Current gallery layout (per category)

Each gallery category displays 4 images in this structure:

Top row:
1. Image 1 = rectangle
2. Image 2 = square-ish / smaller block

Bottom row:
3. Image 3 = square-ish / smaller block
4. Image 4 = rectangle

## Recommended crop ratios

### Image 1 and Image 4
- Shape: horizontal rectangle
- Recommended crop ratio: around **7:5** or **4:3**
- Good export examples:
  - 1400 x 1000 px
  - 1600 x 1200 px
  - 1200 x 900 px
- Any size is okay as long as the ratio is similar.

### Image 2 and Image 3
- Shape: square or almost square
- Recommended crop ratio: **1:1**
- Good export examples:
  - 1000 x 1000 px
  - 1200 x 1200 px
  - 1500 x 1500 px
- Any size is okay as long as the ratio is square.

## Why this helps

The website uses `object-fit: cover`, so slight automatic cropping can still happen depending on screen size and container shape.

If you pre-crop images to the recommended ratios above, the final on-site crop usually looks cleaner and keeps key subjects better framed.

## Simple summary

Before uploading:
- Crop image 1 and image 4 as horizontal rectangle photos.
- Crop image 2 and image 3 as square photos.
- Export images at good quality.
- The exact pixel size does not have to match perfectly.
- The ratio matters more than the exact number of pixels.
